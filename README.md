# نظام المبيعات (my-system)

نظام مبيعات بسيط يعمل بالكامل في المتصفح (HTML + CSS + JavaScript) دون أي خادم. الواجهة بالعربية (RTL).

## المزايا
- **لوحة تحكم** بإجماليات المبيعات والمشتريات وعدد الأصناف والزبائن وآخر الفواتير.
- **الأصناف**: إضافة/حذف، أكواد، أسعار شراء وبيع، كمية ووحدة، وبحث.
- **فواتير البيع**: اختيار الزبون والأصناف، خصم الكمية من المخزون تلقائياً، وعرض الفاتورة وطباعتها.
- **المشتريات**: تسجيل فواتير الشراء وزيادة المخزون وتحديث سعر الشراء.
- **الزبائن وكشف الحساب**: أرصدة محسوبة من الحركات، كشف حساب قابل للطباعة.
- **حفظ تلقائي** في `localStorage` (تبقى البيانات بعد تحديث الصفحة).
- **نسخ احتياطي/استيراد** لقاعدة البيانات بصيغة JSON.

## التشغيل
لا حاجة لأي تثبيت — افتح `index.html` في المتصفح مباشرة:

```bash
# أو شغّل خادماً محلياً بسيطاً
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البيانات
تُخزَّن البيانات محلياً في متصفحك تحت المفتاح `my_sales_db`. استخدم زرّي **نسخة احتياطية** و**استيراد** في الشريط الجانبي لحفظ/استرجاع بياناتك (ملف JSON).

## ملاحظات
- التطبيق أحادي المستخدم ويعتمد تخزين المتصفح؛ لتعدّد المستخدمين أو المزامنة عبر الأجهزة يلزم لاحقاً ربطه بخادم/قاعدة بيانات.
